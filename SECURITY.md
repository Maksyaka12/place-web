# Security

Place handles real funds: reward campaigns and claims, launches, swaps, staking and agent wallets on Base. If you find
a vulnerability, please tell us privately first and give us time to fix it.

## Report a vulnerability

Report it through [GitHub security advisories](https://github.com/Maksyaka12/place-web/security/advisories/new) or send
a direct message to either contact:

- X: [@mksvibe](https://x.com/mksvibe)
- Telegram: [@mksvibe_base](https://t.me/mksvibe_base)

Please don't open a public issue or share details publicly until it is fixed. Include what you found, the steps to reproduce
it, and the contract address or page affected.

## Scope

- The Place app and its API
- The contracts in [contracts/](contracts/), with addresses in [contracts/DEPLOYMENTS.md](contracts/DEPLOYMENTS.md)
- The agent skills in [frontend/public/skills/](frontend/public/skills/)

Place Launch contracts are covered by the policy in
[place-contracts](https://github.com/Maksyaka12/place-contracts/blob/dev/SECURITY.md).

Please test against your own wallets and never touch funds or data that aren't yours.
